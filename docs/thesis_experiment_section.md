# 实验设计与结果分析

本节面向基于检索增强生成（RAG）的中文专业知识问答系统，在真实论文索引知识库上开展答案可靠性对比实验，比较无约束基线（Baseline）与引入证据支持率与相关性阈值的守护式配置（Guarded）在多项可靠性指标上的差异。指标定义与 RAG 可靠性评测框架参见项目内《RAG 可靠性评测与幻觉抑制：知识与公式速览》。

## 实验目标

1. **验证守护策略对拒答行为的影响**：在知识库无法充分支持的问题（不可回答用例）上，系统能否减少“凭空编造”，并以拒答或低置信输出代替不可靠答案。
2. **在固定检索与生成管线下的对比**：在相同的检索方法（BM25）、生成方式（抽取式）与 `top_k` 条件下，仅通过 `min_support_rate`、`min_relevance_overlap` 等阈值引入守护逻辑，隔离“幻觉抑制与拒答策略”本身带来的效果，避免与检索器或生成器替换相混淆。
3. **多维度刻画答案与证据的一致性**：除引用层面的命中率外，从平均证据支持率、平均幻觉率与拒答准确率等角度综合观察系统行为，并与理论上的支持率、幻觉率定义（陈述级支持判定后聚合）相呼应。

## 数据集

实验采用面向真实已索引 AI 领域论文构建的问答评测集，数据文件为 `datasets/real_paper_answer_eval_cases.json`。该集合特点如下。

- **规模**：共 20 条用例；其中可回答（`answerable: true`）12 条，不可回答 8 条。可回答用例均绑定期望证据所在的 `expected_document_id` 与 `expected_chunk_index`，用于与检索与引用行为对齐；不可回答用例用于检验系统在“库外或证据不足”场景下是否应拒答。
- **主题与语言**：问题围绕 Self-RAG、RAG 事实性、幻觉评测、引用与忠实度等英文检索式查询，知识库来源于当前索引的真实论文 PDF 切块，属于垂直领域文献问答设定。
- **复现说明**：JSON 头部注释指出，若在系统中重新上传文档，文档标识可能变化，评测集需按流程重建；本实验报告对应一次固定索引状态下的跑数结果（记录时间见下节结果表来源）。

## Baseline 与 Guarded 配置

两组实验除下表所列差异外，其余保持一致，以保证可比性。

| 项目 | Baseline | Guarded |
|------|----------|---------|
| 检索方法 `method` | bm25 | bm25 |
| 生成器 `generator` | extractive（抽取式） | extractive（抽取式） |
| 检索条数 `top_k` | 3 | 3 |
| 最小证据支持率 `min_support_rate` | 不启用（—） | 0.5 |
| 最小相关性重叠 `min_relevance_overlap` | 不启用（—） | 0.35 |

**含义简述**：Guarded 配置在生成或输出前对检索片段与候选答案施加支持度与相关性门槛，意图过滤证据不足或检索-query 对齐过弱的回答路径，从而抬高对不可回答样本的拒答倾向；Baseline 不设上述阈值，便于观察“无守护”时的默认行为。

## 评价指标

指标与《知识与公式速览》中的可靠性评测框架一致，并结合本系统实现可落地的统计项说明如下。

1. **用例计数**  
   - `total`：参与评测的总问题数。  
   - `answerable_total` / `unanswerable_total`：可回答与不可回答子集规模。

2. **引用命中率 `citation_hit_rate`**  
   对应“答案是否有效挂靠到检索证据”的一类检查：若答案中的引用或证据指针落在预期检索/标注证据范围内，则计为命中。可与公式速览中的引用准确率、Recall@K 等概念对照理解；本实验中二者均报告为聚合后的比率。

3. **拒答准确率 `refusal_accuracy`**  
   对不可回答问题，系统正确拒答（或不输出虚构事实性断言）的比例：  
   \(\text{RefusalAccuracy} = \frac{\text{正确拒答的不可回答题数}}{\text{不可回答题总数}}\)。  
   该指标直接反映知识库外或证据不足场景下的可靠性。

4. **平均证据支持率 `mean_support_rate` 与平均幻觉率 `mean_hallucination_rate`**  
   将答案拆为若干陈述，对每条陈述判断是否存在检索证据支持（`support(a_i, Z) \in \{0,1\}`），则  
   \(\text{SupportRate} = \frac{1}{n}\sum_i support(a_i, Z)\)，  
   \(\text{HallucinationRate} = 1 - \text{SupportRate}\)。  
   实验报告中在全体用例上报告支持率与幻觉率的样本均值，用于观察整体“陈述—证据”对齐程度。需注意：当系统对不可回答问题选择拒答或极短输出时，分母与空证据计分方式会影响均值，应与 `refusal_accuracy` 联合解读（见结果分析）。

## 实验结果

以下汇总数据摘自评测报告 `reports/answer_eval_report_real_papers.md`（实验记录时间：2026-04-28T14:03:50+08:00，数据集路径：`datasets/real_paper_answer_eval_cases.json`）。

**表：Baseline 与 Guarded 汇总指标对比**

| 指标 | 说明 | Baseline | Guarded |
|------|------|:--------:|:-------:|
| `total` | 用例总数 | 20 | 20 |
| `answerable_total` | 可回答用例数 | 12 | 12 |
| `unanswerable_total` | 不可回答用例数 | 8 | 8 |
| `citation_hit_rate` | 引用命中率 | 1.0000 | 1.0000 |
| `refusal_accuracy` | 拒答准确率 | 0.0000 | 0.6250 |
| `mean_support_rate` | 平均证据支持率 | 0.9345 | 0.7008 |
| `mean_hallucination_rate` | 平均幻觉率 | 0.0655 | 0.2992 |

**关键相对变化（Guarded 相对 Baseline）**

- `citation_hit_rate`：+0.0000（持平）。  
- `refusal_accuracy`：+0.6250（由 0 提升至 0.6250）。  
- `mean_hallucination_rate`：+0.2336（由 0.0655 升至 0.2992）。

## 结果分析

1. **引用命中率**  
   两组 `citation_hit_rate` 均为 1.0000，说明在本批可统计的用例上，答案与预期引用/证据挂靠关系未被破坏；守护阈值未以牺牲“能挂上引用”为代价换取拒答，检索与抽取链路在引用层面保持稳定。

2. **拒答准确率显著提升**  
   Baseline 在 8 道不可回答题上拒答准确率为 0，表明无阈值时系统倾向于仍给出表面完整答案，存在编造风险。Guarded 将 `refusal_accuracy` 提升至 0.6250，说明 `min_support_rate` 与 `min_relevance_overlap` 共同作用下，模型更有可能在证据薄弱时转向拒答或弱化断言，与公式速览中“拒答阈值与置信度控制”的设计目标一致。

3. **平均幻觉率上升的含义**  
   `mean_hallucination_rate` 从 0.0655 升至 0.2992，不宜单独解读为“幻觉恶化”。报告中的简短结论指出：拒答或极短答案在陈述拆分与空证据计分下可能拉高整体幻觉率统计；此时应优先以 `refusal_accuracy` 与逐例行为核对为主，必要时对“拒答样本”单独分层报告支持率/幻觉率，避免与可回答子集的忠实度指标混平均。

4. **平均支持率下降与行为权衡**  
   `mean_support_rate` 从 0.9345 降至 0.7008，与幻觉率上升互为补数关系在定义上成立；结合拒答提升，可理解为系统在全局平均意义上更保守——部分原先“流畅但不可靠”的陈述被替换为拒答或非支持计分，需在论文中明确这一权衡属于可靠性优先策略的可预期现象。

## 局限性

1. **样本规模**：20 条用例、12/8 的可答/不可答划分使置信区间较宽，统计显著性有限；结论适用于“方法趋势说明”，推广到更大语料与更多领域需扩展评测集。

2. **领域与语言偏置**：当前用例以英文关键词式问题为主，知识库为 AI 论文；中文专业知识场景下的表述、分词与 BM25 行为可能与本文结果存在差异。

3. **指标耦合与定义细节**：全局平均的 `mean_hallucination_rate` / `mean_support_rate` 对拒答表述的切分与“无陈述”边界敏感；更严谨的做法是对 `answerable` 与 `unanswerable` 子集分别报告忠实度与拒答指标，并辅以人工抽检。

4. **未覆盖的对比维度**：实验未改变 `method`、`generator` 与 `top_k`，未涉及混合检索、重排序或生成式模型；与公式速览中“多 baseline、多方法”的理想实验矩阵相比，本文块仅验证守护阈值在固定管线上的增量效果。

5. **索引与可复现性**：数据集注释表明重新上传文档可能导致 `document_id` 变化，需固定知识库版本或自动化重建评测用例以保证他人复现。
